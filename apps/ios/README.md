# iOS app (SwiftUI)

Thin client: renders server responses, caches them in SwiftData, queues offline writes with idempotency keys. No business rules (`docs/02-architecture.md`, "Thin clients").

- **M0**: only `Hushold/DesignSystem/DesignTokens.swift`, generated by `scripts/gen-tokens-swift.sh` from `contracts/design-tokens/tokens.json`. Do not edit it by hand.
- **M1**: Xcode project `Hushold`, network layer generated from `contracts/openapi/core-service.yaml`, AppAuth sign-in against Keycloak. See `tasks/M1-ledger.md`, part C.
